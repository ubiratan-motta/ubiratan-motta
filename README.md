## 🚀 Transformando dados em valor para negócios

Sou **Data Engineer**, **Software Developer** e **Technical Lead**, com foco em construir soluções escaláveis que conectam **dados, cloud, automação e estratégia de negócio**.

Atuo ajudando empresas e times a saírem do caos operacional para uma estrutura mais inteligente, automatizada e orientada por dados. Meu trabalho envolve desde a construção de pipelines robustos até a definição de arquiteturas modernas, sustentáveis e preparadas para crescimento.

Mais do que escrever código, meu objetivo é criar soluções que gerem impacto real:

**redução de custos, ganho de eficiência, confiabilidade operacional e melhor tomada de decisão.**

- Engenharia de Dados

Tenho direcionado minha atuação para projetos onde tecnologia não é apenas ferramenta, mas parte essencial da estratégia de crescimento do negócio.
